Hallucination during long periods of non-speech—such as repeating the last spoken phrase, looping gibberish, or generating ghost text—is a common failure mode in sequence-to-sequence Transformer ASR models like NVIDIA Canary and OpenAI Whisper. Because auto-regressive decoders are conditioned to constantly output tokens, blank audio forces them to predict sequences based purely on prior context and internal bias.

The industry standard approach is a **layered defense architecture** using Voice Activity Detection (VAD) alongside target decoding parameters and post-processing filters.

---

### Layer 1: VAD Pre-processing (Most Effective)

The single most impactful solution is to ensure non-speech segments never reach the ASR decoder.

* **Integrate Silero VAD:** Run a lightweight VAD model like [Silero VAD](https://github.com/snakers4/silero-vad?utm_source=gemini) prior to calling Canary. Slice the audio into valid speech segments and feed only those timestamps into the ASR pipeline.
* **Trim Boundary Silence:** If you are processing fixed-length chunks, use `ffmpeg` or `pydub` with a decibel threshold filter (`silenceremove`) to strip head/tail silence. Silences at audio chunk boundaries are primary triggers for hallucination loops.

---

### Layer 2: Adjust Canary Decoding Parameters

If you are invoking Canary via NVIDIA NeMo, adjust the greedy/beam search parameters to disallow speculative decoder behavior during low-confidence audio:

* **Temperature:** Keep `temperature = 0.0` (greedy decoding). Higher temperatures force the model to explore low-probability sequence paths during empty audio.
* **Repetition Penalty:** Enable or increase the repetition penalty (e.g., `repetition_penalty = 1.2` to `1.5`) in NeMo's decoding configuration to break repetitive token-looping.
* **No-Speech Threshold:** Adjust the internal silence/non-speech probability threshold if exposed in your inference script to force early termination on quiet frames.

---

### Layer 3: Audio Pre-processing (Noise Removal)

Low-level static, background air-conditioning noise, or microphone hum can prevent simple amplitude-based silence detection from triggering.

* **Denoise Background:** Pre-filter audio using a fast noise reducer (such as DeepFilterNet or RNNoise). Cleaning low-level hiss makes VAD segmentation significantly more accurate.

---

### Layer 4: Post-Processing Delooping Filters

Implement a light post-processing check on the generated output transcript:

* **N-gram Repetition Check:** Scan the transcript using a regex or simple string matcher to detect repeated phrase loops (e.g., words repeated more than 3 times consecutively). If detected, discard or truncate the tail end of the output.
* **Timestamp-to-Audio Verification:** Match Canary's predicted word-level timestamps against the RMS energy of the corresponding raw audio segment. If Canary produces text during a window where audio power is below an acceptable noise floor (e.g., < -45 dBFS), automatically strip those words.

Here is how to run **Silero VAD** on a WAV file in Python to extract speech timestamps, chunk the audio into active speech segments, and prepare it for ASR models like Canary.

### Python Script

```python
import torch
from silero_vad import load_silero_vad, get_speech_timestamps
import torchaudio

# 1. Load the pre-trained Silero VAD model
model = load_silero_vad()

# 2. Load and prepare your WAV file
audio_path = "your_audio_file.wav"
wav, sample_rate = torchaudio.load(audio_path)

# Silero VAD works best on single-channel (mono) audio at 16kHz
if wav.shape[0] > 1:
    wav = torch.mean(wav, dim=0, keepdim=True)

if sample_rate != 16000:
    resampler = torchaudio.transforms.Resample(orig_freq=sample_rate, new_freq=16000)
    wav = resampler(wav)
    sample_rate = 16000

# Flatten to 1D tensor
wav_mono = wav.squeeze(0)

# 3. Get speech timestamps
# Returns a list of dicts: [{'start': sample_idx, 'end': sample_idx}, ...]
speech_timestamps = get_speech_timestamps(
    wav_mono,
    model,
    threshold=0.5,                  # Speech probability threshold
    min_speech_duration_ms=250,      # Ignore speech shorter than 250ms
    min_silence_duration_ms=100,     # Merge speech splits separated by < 100ms
    return_seconds=True             # Returns timestamps in seconds (float)
)

print(f"Detected {len(speech_timestamps)} speech segments:")
for i, segment in enumerate(speech_timestamps):
    print(f"Segment {i+1}: {segment['start']:.2f}s -> {segment['end']:.2f}s")

# 4. Extract and stitch speech-only audio (removes non-speech hallucinations)
speech_chunks = []
for segment in get_speech_timestamps(wav_mono, model, return_seconds=False):
    speech_chunks.append(wav_mono[segment['start']:segment['end']])

if speech_chunks:
    clean_speech_wav = torch.cat(speech_chunks, dim=0)
    
    # Save trimmed WAV file ready for ASR model
    torchaudio.save("clean_speech.wav", clean_speech_wav.unsqueeze(0), sample_rate)
    print("\nSaved trimmed speech-only audio to 'clean_speech.wav'")

```

---

### Key Parameter Tuning for ASR

* **`threshold` (Default `0.5`):** Lowering this (e.g., `0.35`) makes the VAD more sensitive to quiet speech or soft voices, but risks capturing background noise. Raising it (e.g., `0.65`) strictly isolates clear speech.
* **`min_silence_duration_ms` (Default `100`):** Increase this (e.g., `300`–`500`) if your speaker pauses briefly mid-sentence. This prevents chopping a single sentence into multiple tiny audio files.
